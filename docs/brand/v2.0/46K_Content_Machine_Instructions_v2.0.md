# 46K Content Machine — Instructions v2.0

**ACTIVE / October 2026.** Add this as the production-specific companion to the v2.0 brand system. It does not override scientific accuracy, editorial review, or user approval.

## Purpose

Produce high-quality 46K articles and supporting assets with minimal manual work while maintaining a consistent, editorial, football-native identity. Prioritize mobile reading and reuse in 46K.com, Instagram and other channels.

## Required context

Read `46K_00_START_HERE_v2.0.md`, `46K_AI_Quick_Context_v2.0.md`, `46K_Official_Logo_Asset_Protocol_v2.0.md` and the relevant sections of the full spec before starting. Follow READ → CLASSIFY → EXTRACT → BRIEF → PRODUCE → VERIFY.

## Article workflow

1. Accept a topic, notes or rough draft from the user.
2. Define audience, editorial purpose, content pillar (UNDERSTAND, ASSESS, DEVELOP or 2046) and article format (Editorial Story, Research Explained or Football Insight).
3. Research and draft; explicitly distinguish WE KNOW / EVIDENCE SUGGESTS / WE THINK. Never invent citations, study results, test validity or predictive accuracy.
4. Create an article-specific visual brief. Generate or select relevant football imagery, diagrams and restrained editorial graphic elements.
5. Compose the article using reusable web components (hero, section, photo, pull quote, evidence note, sources, related reading, CTA). Do not make every article visually identical.
6. **Generate all supporting imagery without a 46K logo.** Add the correct locked PNG logo later as a separate deterministic layer only where needed.
7. Prepare a preview/draft in the website workflow. The user reviews meaningful content, safety and major visual decisions before publication.
8. Verify responsive layout, source citations, alt text, image licensing/rights, spelling, and actual exported visuals. Never claim a draft is published until it is.

## Logo selection

- Full Signature Light: on light/Paper background when there is enough width.
- Full Signature Dark: on dark/Graphite background when there is enough width.
- Essential Light: compact use on light/Paper background.
- Essential Dark: compact use on dark/Graphite background.
- Only files in `logos/` of this v2.0 bundle are official. All earlier SVG logos are superseded.
- If a logo original is missing, request it. Do not generate an imitation.

## Design

- Paper `#F5F2E9`, Graphite `#383D3E`, Pitch `#285C43`, Gold accent `#C29D45`.
- Editorial generally dominates long-form articles; Core for evidence/data; Performance for football energy and action. The gear follows the content, not the platform.
- Approved optional background: `backgrounds/46K_Paper_Graphite_Texture.png`. It is not mandatory for all assets.
- Do not make unsupported talent predictions, use fabricated metrics or present hypotheses as settled science.

## Publication boundary

Content Machine may prepare drafts and previews autonomously, but must not publish or make significant safety/brand decisions without the user's agreed approval workflow. Assessment purchases, test responses and personal results require a separately designed secure system; do not place them in the public GitHub content repository.
