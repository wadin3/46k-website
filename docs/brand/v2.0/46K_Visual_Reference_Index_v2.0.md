# GLOBAL REFERENCE RULE

The images in this package are **visual calibration**, not a replacement
for the written brand specification.

Priority:

1.  explicit current task
2.  locked written 46K rules
3.  locked production assets
4.  the specific qualities identified below for each STYLE_REFERENCE
5.  incidental details visible in a reference image

If a reference image contains a wrong hex value, old copy, invented
data, a malformed logo, an obsolete phrase, or an AI-generated font
label, **ignore it**.

Use text for rules.  
Use approved images for visual calibration.  
Use locked assets for exact production.

# HOW AN AI SHOULD USE THIS PACKAGE

For a new visual task:

1.  Read Quick Context.
2.  Follow Asset Production Protocol.
3.  Identify dominant gear.
4.  Select **only the 1–3 visual references most relevant to the task**.
5.  Extract the specific visual qualities listed in this index.
6.  Compile an asset-specific brief.
7.  Produce with the appropriate method.
8.  Verify against written rules and the selected references.

Do not dump all reference images into every generation request.

For example:

### Core information model

Use primarily:

- REF 03 Graphic Language
- REF 05 Layout, Data & UI

### Player-facing Performance visual

Use primarily:

- REF 04 Photography
- REF 08 Performance Calibration

### Research article / 2046 essay

Use primarily:

- REF 02 Overall Creative Direction
- REF 04 Photography

### Cross-channel campaign/application

Use primarily:

- REF 06 Applications
- plus the gear-specific reference needed

# FINAL PRINCIPLE

The purpose of the visual reference library is not to make every new
asset look like a copy of an old prospect.

It exists to calibrate the AI's visual taste:

- how much
- how dark
- how sparse
- how physical
- how analytical
- how football-native
- how premium
- how energetic

The written system defines **what 46K is**.

The visual references show **what that feels like when it is working**.
